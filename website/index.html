Stream Deck Plugin für Claude Code

Claude arbeitet. Du siehst es auf einen Blick.

ClaudeDeck zeigt auf deinem Elgato Stream Deck, was jede deiner Claude Code Sessions gerade macht. Fragt Claude um Erlaubnis, blinkt die Taste, und du entscheidest mit einem Druck. Kein Fensterwechsel, kein Suchen nach dem richtigen Tab.

Installieren Auf GitHub ansehen

Immer im Blick

Jede Session bekommt eine eigene Taste mit Namen, Zustand und wie voll ihr Gedächtnis ist.

Ein Druck genügt

Anfragen von Claude erlaubst oder verbietest du direkt am Stream Deck.

Sofort zur Session

Ein Druck auf eine Status-Taste öffnet genau diese Session in Claude.

Die Tasten

ClaudeDeck bringt sechs Aktionen mit. Du ziehst sie in der Stream Deck App auf beliebige Tasten, so viele du willst.

Claude Status

Die wichtigste Taste. Sie zeigt eine Session mit

  • Titel der Session (oder dem Projektordner),
  • Zustand, zum Beispiel Working oder Done,
  • Kontext: wie viel vom Gedächtnis der Session schon belegt ist, als Prozentzahl und Balken.

Kurz drücken öffnet die Session in Claude Desktop oder holt das passende Fenster nach vorne. Lang drücken (über eine halbe Sekunde) bricht die laufende Antwort dieser Session ab.

Mehrere Status-Tasten füllen sich automatisch mit deinen aktuellen Sessions. Wenn du willst, legst du eine Taste fest auf einen Projektordner.

Allow, Always, Deny

Möchte Claude etwas tun, das deine Zustimmung braucht, zum Beispiel einen Befehl ausführen, leuchten diese drei Tasten auf. Darauf steht, was Claude vorhat und in welchem Projekt.

  • Allow erlaubt es dieses eine Mal.
  • Always erlaubt es und fragt in dieser Session nicht mehr nach.
  • Deny lehnt ab.

Ohne offene Anfrage bleiben die Tasten gedimmt. Fragt Claude eine inhaltliche Frage, bleiben sie dunkel, und nur die Status-Taste blinkt lila.

Plan Usage

Zeigt, wie viel deines Claude-Kontingents verbraucht ist: das 5-Stunden-Limit und das 7-Tage-Limit.

Drücken zeigt drei Sekunden lang, wann die Limits wieder zurückgesetzt werden. Ist ein Limit erreicht, steht oben rot LIMIT.

Braucht das optionale Zusatzmodul, siehe Installation.

Claude Window

Holt Claude Desktop groß in den Vordergrund. Ist es schon groß, minimiert ein weiterer Druck das Fenster. Die Taste zeigt immer, was beim nächsten Druck passiert.

Was die Farben bedeuten

Die Farbe einer Status-Taste verrät dir sofort, ob du gebraucht wirst.

Der Kontext-Balken wird ab 50 % gelb und ab 80 % rot. Dann lohnt sich bald eine neue Session.

Installation

Du brauchst Windows 10 oder 11, ein Elgato Stream Deck mit der Stream Deck App ab Version 7.1 und Claude Desktop oder Claude Code im Terminal.

  1. Stream Deck Plugin installieren

    Ein fertiges Installationspaket folgt. Bis dahin installierst du das Plugin aus dem Quellcode. Dafür brauchst du Node.js ab Version 24:

    git clone https://github.com/Rezondes/ClaudeDeck.git
cd ClaudeDeck
npm install
npm run build
npm run link

    Danach findest du in der Stream Deck App die Kategorie ClaudeDeck. Zieh die Tasten, die du möchtest, auf dein Stream Deck.

  2. Claude Code verbinden

    Gib in Claude Desktop (Code-Tab) oder im Terminal in Claude Code diese zwei Befehle ein:

    /plugin marketplace add Rezondes/ClaudeDeck
/plugin install claudedeck@claudedeck

    Starte Claude danach einmal neu. Ab jetzt meldet Claude seinen Zustand an dein Stream Deck.

  3. Optional: Zusatzmodul für mehr Details

    Das Zusatzmodul liefert den genauen Kontext-Wert, die Daten für die Plan Usage Taste und ermöglicht das Abbrechen per langem Druck. Im ClaudeDeck-Ordner:

    npm run module:install

    Neue Sessions laden das Modul dann automatisch. Entfernen geht genauso einfach mit npm run module:remove.

    Das Modul nutzt eine Vorab-Funktion von Claude Code, die sich noch ändern kann. ClaudeDeck funktioniert auch ohne es.

Häufige Fragen

Was passiert, wenn mein Stream Deck aus ist?

Nichts Schlimmes. Läuft das Stream Deck Plugin nicht, fragt Claude ganz normal auf dem Bildschirm nach. Drückst du innerhalb von 60 Sekunden keine Taste, erscheint die Anfrage ebenfalls wie gewohnt.

Werden meine Daten irgendwohin geschickt?

Nein. Claude und das Stream Deck sprechen nur auf deinem eigenen Rechner miteinander. Webseiten im Browser können sich nicht dazwischenschalten.

Ich habe mehrere Anfragen gleichzeitig. Welche erlaube ich?

Allow, Always und Deny wirken immer auf die älteste offene Anfrage. Auf der Taste siehst du, um welchen Befehl und welches Projekt es geht.

Kann ich eine Taste fest einem Projekt zuordnen?

Ja. Wähle die Status-Taste in der Stream Deck App aus und trag unter Project folder den Projektordner ein. Mit Latest session only zeigt die Taste immer die zuletzt aktive Session dieses Ordners.

Läuft ClaudeDeck auf dem Mac?

Noch nicht. ClaudeDeck unterstützt derzeit nur Windows.

Ist das ein offizielles Produkt von Anthropic?

Nein. ClaudeDeck ist ein inoffizielles Community-Projekt und steht in keiner Verbindung zu Anthropic oder Elgato.
