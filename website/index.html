Dein Stream Deck weiß, was Claude gerade tut.

ClaudeDeck legt jede Claude Code Session auf eine eigene Taste. Du siehst, wer arbeitet, wer fertig ist und wer auf dich wartet. Fragt Claude um Erlaubnis, entscheidest du mit einem Druck.

Installieren Quellcode ansehen

Für Windows, Stream Deck 7.1 und neuer, Claude Desktop und Claude Code im Terminal. Kostenlos und Open Source.

Eine Anfrage, ein Druck

So sieht es aus, wenn Claude während der Arbeit deine Erlaubnis braucht.

  1. Claude arbeitet

    Die Taste leuchtet blau. Der Balken zeigt, wie voll das Gedächtnis der Session ist.

  2. Claude fragt

    Die Taste blinkt gelb. Claude möchte etwas tun, das deine Zustimmung braucht.

  3. Du drückst

    Allow, Always oder Deny. Auf der Taste steht, was Claude vorhat und wo.

  4. Fertig

    Grün heißt erledigt. Ein Druck auf die Taste bringt dich direkt zur Session.

Sechs Tasten, frei verteilbar

Zieh sie in der Stream Deck App auf dein Gerät. Status-Tasten kannst du so oft verwenden, wie du Sessions im Blick haben willst.

Claude Status

Zeigt den Titel einer Session, ihren Zustand und wie viel Kontext schon belegt ist. Neue Sessions landen automatisch auf freien Tasten, oder du legst eine Taste fest auf einen Projektordner.

Kurz drücken
öffnet genau diese Session in Claude Desktop.
Lang drücken
bricht die laufende Antwort ab.

Allow, Always, Deny

Leuchten auf, sobald Claude um Erlaubnis bittet. Allow erlaubt es einmal, Always für den Rest der Session, Deny lehnt ab. Ohne offene Anfrage bleiben sie gedimmt.

Stellt Claude dir eine inhaltliche Frage, bleiben diese Tasten aus. Dann blinkt nur die Status-Taste lila.

Plan Usage

Wie viel von deinem Claude-Kontingent verbraucht ist, für das 5-Stunden- und das 7-Tage-Limit. Ein Druck zeigt drei Sekunden lang, wann sie zurückgesetzt werden.

Braucht das optionale Zusatzmodul.

Claude Window

Holt Claude Desktop groß nach vorne oder legt es wieder weg. Die Taste zeigt immer, was der nächste Druck macht.

Farben lesen lernen

Nach einem Tag erkennst du aus dem Augenwinkel, ob du gebraucht wirst.

  • WorkingClaude arbeitet.
  • ApproveWartet auf deine Erlaubnis.
  • InputHat dir eine Frage gestellt.
  • DoneFertig, bis du weiterschreibst.
  • LimitKontingent erreicht oder Fehler.
  • IdleDie Session ruht.
  • N waitingSessions ohne eigene Taste warten.

Der Kontext-Balken wird ab 50 % gelb und ab 80 % rot. Dann lohnt sich bald eine neue Session.

In drei Schritten eingerichtet

Ein fertiges Installationspaket folgt. Bis dahin richtest du ClaudeDeck aus dem Quellcode ein. Dafür brauchst du Node.js ab Version 24.

  1. Stream Deck Plugin installieren

    git clone https://github.com/Rezondes/ClaudeDeck.git
cd ClaudeDeck
npm install
npm run build
npm run link

    In der Stream Deck App erscheint die Kategorie ClaudeDeck. Zieh die Tasten auf dein Gerät.

  2. Claude Code verbinden

    In Claude Desktop (Code-Tab) oder im Terminal in Claude Code eingeben:

    /plugin marketplace add Rezondes/ClaudeDeck
/plugin install claudedeck@claudedeck

    Claude einmal neu starten. Ab jetzt meldet jede Session ihren Zustand an dein Stream Deck.

  3. Zusatzmodul einschalten optional

    Liefert den genauen Kontext-Wert, die Daten für Plan Usage und das Abbrechen per langem Druck. Im ClaudeDeck-Ordner:

    npm run module:install

    Nutzt eine Vorab-Funktion von Claude Code, die sich noch ändern kann. Entfernen mit npm run module:remove. ClaudeDeck funktioniert auch ohne.

Häufige Fragen

Was passiert, wenn mein Stream Deck aus ist?

Nichts Schlimmes. Läuft das Plugin nicht, fragt Claude ganz normal auf dem Bildschirm nach. Drückst du innerhalb von 60 Sekunden keine Taste, erscheint die Anfrage ebenfalls wie gewohnt.

Werden meine Daten irgendwohin geschickt?

Nein. Claude und das Stream Deck sprechen nur auf deinem eigenen Rechner miteinander. Webseiten im Browser können sich nicht dazwischenschalten.

Mehrere Anfragen gleichzeitig: welche erlaube ich?

Allow, Always und Deny wirken immer auf die älteste offene Anfrage. Auf der Taste siehst du, um welchen Befehl und welches Projekt es geht.

Kann ich eine Taste fest einem Projekt zuordnen?

Ja. Wähle die Status-Taste in der Stream Deck App aus und trag unter Project folder den Ordner ein. Mit Latest session only zeigt sie immer die zuletzt aktive Session dieses Ordners.

Läuft ClaudeDeck auf dem Mac?

Noch nicht. ClaudeDeck unterstützt derzeit nur Windows.

Ist das ein offizielles Produkt von Anthropic?

Nein. ClaudeDeck ist ein inoffizielles Community-Projekt und steht in keiner Verbindung zu Anthropic oder Elgato.
