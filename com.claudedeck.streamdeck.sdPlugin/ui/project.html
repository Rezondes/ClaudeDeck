Help

Pick a folder you share with Claude Code projects (Remote Control in Claude Desktop). The key shows how many project threads currently work in that folder on this PC and the most urgent state: Input (a thread waits for you), Error, Working, Done or Idle. Archived threads are not counted. Threads that run only in the cloud are not visible to ClaudeDeck. Press the key to open the most urgent thread in Claude Desktop (the most recently active one if several share that state); without threads it brings Claude Desktop forward. Use the Claude Reload key to refresh everything at once.
